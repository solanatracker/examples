# Get Solana Token Price (REST)

Tutorial: [https://www.solanatracker.io/resources/get-solana-token-price-api](https://www.solanatracker.io/resources/get-solana-token-price-api)

Source: [solanatracker/examples/01-get-solana-token-price-api](https://github.com/solanatracker/examples/tree/main/01-get-solana-token-price-api)

## Setup

```bash
git clone https://github.com/solanatracker/examples.git
cd examples/01-get-solana-token-price-api
cp .env.example .env
npm install
npm start
```

## Run online

Open in [StackBlitz](https://stackblitz.com/github/solanatracker/examples?file=01-get-solana-token-price-api%2Fsrc%2Findex.ts) (free) — add your keys to `.env`, then `npm start`. gRPC examples require a local Node runtime because of native dependencies.
