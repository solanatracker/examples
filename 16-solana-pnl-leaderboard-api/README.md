# PnL v2 Leaderboard

Tutorial: [https://www.solanatracker.io/resources/solana-pnl-leaderboard-api](https://www.solanatracker.io/resources/solana-pnl-leaderboard-api)

Source: [solanatracker/examples/16-solana-pnl-leaderboard-api](https://github.com/solanatracker/examples/tree/main/16-solana-pnl-leaderboard-api)

## Setup

```bash
git clone https://github.com/solanatracker/examples.git
cd examples/16-solana-pnl-leaderboard-api
cp .env.example .env
npm install
npm start
```

## Run online

Open in [StackBlitz](https://stackblitz.com/github/solanatracker/examples?file=16-solana-pnl-leaderboard-api%2Fsrc%2Findex.ts) (free) — add your keys to `.env`, then `npm start`. gRPC examples require a local Node runtime because of native dependencies.
