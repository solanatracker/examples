# Reduce RPC Latency

Tutorial: [https://www.solanatracker.io/resources/reduce-solana-rpc-latency](https://www.solanatracker.io/resources/reduce-solana-rpc-latency)

Source: [solanatracker/examples/06-reduce-solana-rpc-latency](https://github.com/solanatracker/examples/tree/main/06-reduce-solana-rpc-latency)

## Setup

```bash
git clone https://github.com/solanatracker/examples.git
cd examples/06-reduce-solana-rpc-latency
cp .env.example .env
npm install
npm start
```

## Run online

Open in [StackBlitz](https://stackblitz.com/github/solanatracker/examples?file=06-reduce-solana-rpc-latency%2Fsrc%2Findex.ts) (free) — add your keys to `.env`, then `npm start`. gRPC examples require a local Node runtime because of native dependencies.
