Source: [solanatracker/examples/07-yellowstone-grpc-setup](https://github.com/solanatracker/examples/tree/main/07-yellowstone-grpc-setup)

## Setup

```bash
git clone https://github.com/solanatracker/examples.git
cd examples/07-yellowstone-grpc-setup
cp .env.example .env
npm install
npm start
```
