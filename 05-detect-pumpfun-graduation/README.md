# Detect Pump.fun Graduations

Tutorial: [https://www.solanatracker.io/resources/detect-pumpfun-graduation](https://www.solanatracker.io/resources/detect-pumpfun-graduation)

Source: [solanatracker/examples/05-detect-pumpfun-graduation](https://github.com/solanatracker/examples/tree/main/05-detect-pumpfun-graduation)

## Setup

```bash
git clone https://github.com/solanatracker/examples.git
cd examples/05-detect-pumpfun-graduation
cp .env.example .env
npm install
npm start
```

## Run online

Open in [StackBlitz](https://stackblitz.com/github/solanatracker/examples?file=05-detect-pumpfun-graduation%2Fsrc%2Findex.ts) (free) — add your keys to `.env`, then `npm start`. gRPC examples require a local Node runtime because of native dependencies.
