# Meteora DLMM gRPC Stream

Tutorial: [https://www.solanatracker.io/resources/meteora-dlmm-transaction-parsing](https://www.solanatracker.io/resources/meteora-dlmm-transaction-parsing)

Source: [solanatracker/examples/10-meteora-dlmm-transaction-parsing](https://github.com/solanatracker/examples/tree/main/10-meteora-dlmm-transaction-parsing)

## Setup

```bash
git clone https://github.com/solanatracker/examples.git
cd examples/10-meteora-dlmm-transaction-parsing
cp .env.example .env
npm install
npm start
```
